Это выполненное тестовое задание на должность PHP-разработчика

Текст задания по которому оно выполнялось можно прочесть в файле `test-case-middle.docx` в корневом каталоге проекта.

Установка в целом стандартна для приложений Yii2:
1. Установить проект через composer
2. Создать БД в MySQL
3. Настроить подключение к БД в файле `config/db.php`
4. Применить миграции `php yii migrate`
5. При необходимости можно наполнить БД тестовыми данными командой: `php yii seed/run`
6. Запустить web-сервер командой `php yii serve`
7. Запустить слушатель очередей командой `php yii queue/listen`

После этого приложение будет полностью функционально и доступно по адресу `http://localhost:8080`

Я решил не реализовывать реальную отправку SMS, однако сделал всю необходимую "обвязку" для возможности реальной отправки уведомлений.
Для реальной отправки достаточно будет модифицировать метод `app\jobs\SendNotificationJob::sendSms()` - сейчас в нем стоит "заглушка".
"Отправленные" сообщения пишутся в лог: `runtime\logs\notifications.log`

При разработке приложения использовалась LLM-модель от Google - в основном просто для советов по неочевидным вещам - вроде, в каком виде лучше хранить в базе ISBN, а так же как более удобная замена для Gii (просил сгенерировать модели по миграции и т.д.)
